# Case Discussion AI Features - Quick Start Guide

## 🤖 Ask AI for Help

### Using @Mentions
Simply mention the AI in any comment to get expert guidance:

```
@Neurotrace explain why this is not breach rhythm?
```

or use the shorthand:

```
@AI what's the difference between spikes and sharp waves here?
```

**The AI button** in the comment box automatically inserts `@Neurotrace ` for you.

### What AI Can Help With
- Explain specific EEG patterns
- Differentiate between similar findings
- Identify artifacts vs. pathological patterns
- Clarify terminology
- Suggest differential diagnoses
- Reference ABRET standards

### Example Questions
- `@Neurotrace is this normal sleep architecture?`
- `@AI why would medication affect this pattern?`
- `@Neurotrace what's the clinical significance of this finding?`

---

## 🔄 Reconcile Different Opinions

When you see conflicting interpretations in the discussion:

1. Click the **"🔄 Reconcile Views"** button at the top
2. Select 2 or more comments with different opinions (checkboxes appear)
3. Click **"Reconcile"** to get AI analysis

### What You'll Get
- **Key Differences:** Clear comparison of the viewpoints
- **Decisive Features:** Which EEG findings resolve the debate
- **Analysis:** Objective assessment of which view is better supported
- **Learning Point:** Educational takeaway from the discussion

### Use This When
- Multiple users suggest different patterns
- Debate between artifact vs. real finding
- Conflicting clinical interpretations
- Focal vs. generalized origin questions

---

## 📋 Structure the Discussion

For long or complex discussions, organize everything into a clear format:

1. Click **"📋 Structure Discussion"** button at the top
2. AI analyzes all comments and creates a summary

### Output Format

**What We Know:**
- Agreed-upon findings
- Clear patterns identified
- Relevant clinical facts

**What We Need:**
- Unanswered questions
- Missing information
- Areas needing clarification

**Working Impression:**
- Current consensus
- Differential diagnoses
- Suggested next steps

### When to Use
- After extensive discussion (5+ comments)
- When new participants join
- Before formulating final impression
- To identify knowledge gaps

---

## 💡 Tips for Best Results

### Writing Good @Mentions
✅ **Good:** "@Neurotrace explain the sharp waves at F7-T3"
❌ **Avoid:** "@AI help" (too vague)

✅ **Good:** "@AI is this breach rhythm or just skull defect artifact?"
❌ **Avoid:** "@Neurotrace diagnosis?" (AI provides education, not diagnosis)

### Using Reconciliation Effectively
- Select comments that truly conflict (not just different aspects)
- 2-3 comments usually work best
- Include the core disagreement in the selected comments

### Structuring at the Right Time
- Wait until discussion has substance (3+ meaningful comments)
- Use periodically in long discussions, not constantly
- Great for summarizing before moving to conclusion

## 🔧 Troubleshooting

**AI not responding?**
- Check spelling: `@Neurotrace` or `@AI`
- Wait 10-15 seconds for processing
- Refresh page if needed

**Reconciliation button disabled?**
- Select at least 2 comments
- Ensure they're user comments (not AI)
- Check you're logged in

**Structure not generating?**
- Need at least 3-4 comments
- Allow 15-20 seconds for complex discussions
- Try again if first attempt fails

2. Read reconciliations to learn decision-making
